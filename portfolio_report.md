## Project Portfolio

### 1. A.I-Hiring
Repository: rohanjha200404/A.I-Hiring

A.I-Hiring is a full-stack recruitment platform that focuses on improving and automating the hiring process. The system is built as a monorepo with a separate frontend and backend, enabling scalable architecture and clear separation of responsibilities.

Key aspects:
- Recruitment workflow support and user management
- Secure authentication and authorization using JWT and bcrypt
- File handling for resume and document uploads
- CSV and PDF processing for operational data handling
- Real-time communication support using Socket.IO
- Dynamic frontend built with React and Vite

This project demonstrates the ability to build a business-facing platform with multiple integrated modules, including security, data processing, and user-facing interaction.

### 2. Inventory Management

This project is a full-stack inventory system designed to help organizations track stock, manage items, and support operational workflows. The architecture follows a common business-application pattern with frontend and backend separation and a database-backed data layer.

Key aspects:

### 4. urlguardAI

### 5. poker_py

Key aspects:
