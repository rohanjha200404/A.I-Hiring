Project Portfolio

1. A.I-Hiring
Repository: rohanjha200404/A.I-Hiring • Stack: React, Node.js, Express, MySQL, Sequelize

A.I-Hiring is a full-stack recruitment platform that focuses on improving and automating the hiring process. The system is built as a monorepo with a separate frontend and backend, enabling scalable application architecture and clear separation of responsibilities.

Key aspects:

  • Recruitment workflow support and user management
  • Secure authentication and authorization using JWT and bcrypt
  • File handling for resume and document uploads
  • CSV and PDF processing for operational data handling
  • Real-time communication support using Socket.IO
  • Dynamic frontend built with React and Vite

This project demonstrates the ability to build a business-facing platform with multiple integrated modules, including security, data processing, and user-facing interaction. It reflects practical experience in full-stack engineering and production-oriented software design.

2. Inventory Management
Repository: rohanjha200404/inventory-management • Stack: React, Vite, Node.js, Express, MySQL

This project is a full-stack inventory system designed to help organizations track stock, manage items, and support operational workflows. The architecture follows a common business-application pattern with frontend and backend separation and a database-backed data layer.

Key aspects:

  • Inventory and stock management workflows
  • Authentication and security for application users
  • CSV import support for operational data ingestion
  • Email integration and communication flows
  • REST-based backend APIs for inventory operations
  • Responsive business dashboard experience

The project shows a strong understanding of internal business tooling, process management, and data visibility. It is highly relevant to software work that supports daily operational decision-making.

4. urlguardAI
Repository: rohanjha200404/urlguardAI • Stack: JavaScript, Node.js, MySQL, Sequelize

urlguardAI is a cybersecurity-focused application built around phishing URL detection using AI-based decision logic. Its primary objective is to analyze URL characteristics and add a layer of security intelligence to suspicious link evaluation.

Key aspects:

  • Cybersecurity and phishing detection concept
  • AI-driven URL classification using reinforcement learning ideas
  • Backend integration with MySQL and Sequelize
  • Frontend visualization and interaction layer

This project highlights the ability to apply artificial intelligence to practical security challenges, showing interest in data-driven decision systems beyond standard business CRUD tools.

5. poker_py
Repository: rohanjha200404/poker_py • Stack: Python, Streamlit

poker_py is an interactive AI poker game implemented in Python using Streamlit. The project combines game logic, card evaluation, and decision-making algorithms to create a playable and demonstrable AI application.

Key aspects:

  • Deck generation and card handling
  • Poker hand evaluation and ranking logic
  • Game-state modeling and betting interactions
  • Q-table based AI decision-making
  • Interactive visual interface using Streamlit

This project is valuable as evidence of algorithmic thinking and the practical application of reinforcement learning concepts in a user-facing environment.
